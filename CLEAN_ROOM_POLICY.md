# BossAI Funding Clean-Room Policy

BossAI Funding is an independent implementation.

The OpenBcon repository is not an implementation source for this project.

Developers and coding agents working on BossAI Funding must not inspect, copy, adapt, translate, port, or otherwise derive implementation details from the OpenBcon repository.

## Forbidden repository

The following path is explicitly prohibited during BossAI Funding work:

`D:\BossAI-Projects\OpenBcon`

Prohibited access includes source code, CSS, TypeScript/TSX, Python, prompts, tests, database schemas, migrations, APIs, README files, product copy, UI components, images, logos, and Git history.

The repository must not be searched, indexed, diffed, opened, or used as a template for this project.

## Permitted sources

Implementation may be derived only from:

1. BossAI Funding requirements authorized by BossAI.
2. BossAI company governance and product requirements.
3. General financing-domain knowledge.
4. Official public technical documentation.
5. Independently designed UI/UX and domain models.
6. License-compatible third-party dependencies and their official documentation.

Public third-party product research may inform general capabilities and user experience, but protected code, non-public implementation details, brand assets, distinctive copy, and proprietary UI assets must not be copied.

## Evidence discipline

Every significant implementation batch must update `IMPLEMENTATION_PROVENANCE.md` with the permitted sources actually used. Third-party packages must be recorded in `THIRD_PARTY_LICENSES.md`.

If a contributor has inspected the forbidden repository during the same implementation task, that contributor must stop and disclose the contamination risk before contributing code to BossAI Funding.
